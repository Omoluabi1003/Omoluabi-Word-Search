# Omoluabi Word Search

JavaScript word-search game with an included grid test.

## Project at a glance

- **Purpose:** JavaScript word-search game with an included grid test.
- **Repository:** https://github.com/Omoluabi1003/Omoluabi-Word-Search
- **Status:** Repository documentation foundation. Review implementation before describing features as production-ready.
- **Audience:** Contributors, technical reviewers and prospective users.

## Getting started

Run `npm test` to execute `test/grid.test.js`; inspect the repository entry point for browser use.

## Scope and limitations

Documented testing covers the included grid test and does not imply full end-to-end coverage.
